## HTML REPORT(CLI) FROM COMMAND LINE IN JMETER

## About This Project
This project demonstrates **HTML Report Generation in Apache JMeter using Non-GUI (CLI) Mode**. It executes performance test plans through command-line commands and automatically generates interactive HTML reports. The reports provide key performance metrics such as response time, throughput, and error percentage. This helps evaluate application performance and identify potential bottlenecks without using the **JMeter GUI**.

## Pre-requisite
- Java

## Tools & Technologies
- Apache Jmeter
- Visual Studio Code
