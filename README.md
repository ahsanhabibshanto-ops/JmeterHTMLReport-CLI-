## HTML REPORT(CLI) FROM COMMAND LINE IN JMETER

## About This Project
This project focuses on generating HTML Reports in Apache JMeter using the Command Line Interface (CLI). It demonstrates how to execute performance test plans through command-line commands and automatically generate detailed, interactive HTML reports. The report provides essential performance metrics, including response time, throughput, error percentage, and transaction statistics. This approach helps analyze application performance, identify potential bottlenecks, and evaluate system behavior under different load conditions without relying on the JMeter GUI.

## Pre-requisite
- Java
